Type: Lookup Relationship
Related Object: Course

👉 Name: Course__c

Student (Lookup to Student)

Student (Lookup)

Validation Rules

“Attendance date cannot be in the future”

Prevent marks > 100:
Marks__c > 100
⚡ STEP 3 — APEX TRIGGERS (only if Flow is not enough)

Go to Developer Console → New Apex Trigger

Example: Auto-update status

trigger StudentStatusTrigger on Attendance__c (after insert, after update) {
    Set<Id> studentIds = new Set<Id>();

    for(Attendance__c a : Trigger.new){
        studentIds.add(a.Student__c);
    }

    List<Student__c> students = [
        SELECT Id, Status__c FROM Student__c WHERE Id IN :studentIds
    ];

    for(Student__c s : students){
        // simple logic placeholder
        s.Status__c = 'Active';
    }

    update students;
}

👉 Use Apex only when Flow becomes limiting.
