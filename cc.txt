“Design and develop a custom application using Salesforce Cloud”

Objects (tables)
Fields
Relationships (sometimes)
Forms (UI)
Basic CRUD operations
Reports / List views

🔴 2. PaaS Deployment (C5, C6, C14, C15)
📌 Common meaning:

Deploy a web application on a cloud platform (Heroku / Render / Netlify / Vercel)

🔧 Implementation Steps (GENERIC PaaS DEPLOYMENT)
🟢 STEP 1: Create Node.js App
npm init -y
npm install express
🟢 STEP 2: Create server.js
const express = require('express');
const app = express();

app.get('/', (req,res)=>{
  res.send("Deployed App Running on PaaS");
});

app.listen(process.env.PORT || 3000);
🟢 STEP 3: Add Procfile (Heroku only)
web: node server.js
🟢 STEP 4: Push to GitHub
git init
git add .
git commit -m "deploy"
git push origin main
🟢 STEP 5: Deploy (choose one)
👉 Render (EASIEST)
Go to render.com
New Web Service
Connect GitHub repo
Deploy
👉 Heroku
heroku login
heroku create app-name
git push heroku main
📊 RESULT

✔ Live URL generated
✔ App accessible on internet




3. Virtual Machine File Transfer (C7, C9, C10, C11, C23, C24, C25, C26)
📌 Common Task:

Transfer 2 text files between two VMs + modify + display before/after

🔧 IMPLEMENTATION STEPS (VERY IMPORTANT)
🟢 STEP 1: Create files on VM1
echo "Hello from VM1" > file1.txt
echo "Second file VM1" > file2.txt
🟢 STEP 2: View content
cat file1.txt
cat file2.txt
🟢 STEP 3: Transfer file using SCP
scp file1.txt user@VM2_IP:/home/user/
scp file2.txt user@VM2_IP:/home/user/
🟢 STEP 4: Login VM2
ssh user@VM2_IP
🟢 STEP 5: Verify files
cat file1.txt
cat file2.txt
🟢 STEP 6: Modify file on VM2
echo "Added on VM2" >> file1.txt
🟢 STEP 7: Send back to VM1 (optional)
scp file1.txt user@VM1_IP:/home/user/



✔ Best tools used
scp (secure copy)
ssh
nano / vim
cat
🔧 Typical Exam Setup (Ubuntu VM1 + VM2)
👉 Step 1: Check SSH service
sudo systemctl status ssh

If not installed:

sudo apt update
sudo apt install openssh-server -y
👉 Step 2: Find IP address
ip a
👉 Step 3: Create file on VM1
echo "Hello from VM1" > file1.txt
👉 Step 4: Transfer file
scp file1.txt user@VM2_IP:/home/user/
👉 Step 5: Verify on VM2
cat file1.txt
